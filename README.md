## The word

**timesink** — the whole internet in a single word.

Every feed, tab, thread and rabbit hole is the same trap: you sit
down for five minutes and surface three hours later, entertained,
informed about nothing, and somehow still scrolling. It is funny
because it is true, and it fits the internet as a whole rather than
any one app, site or mood.

## How it runs

`main.ts` writes the single word to `/output/entry.txt` — nothing
else. Run it with Node 22.18+:

```sh
node main.ts
```

The output is exactly `timesink` (8 characters), inside the gate of
1–30 UTF-8 characters.
